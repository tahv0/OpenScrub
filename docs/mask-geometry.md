# Report mask geometry

`poly` is a list of outer rings, each a list of `[x, y]` points normalized to the detection's unpadded `cbox` (0 to 1). `poly_holes` is optional: when present, it has one entry per outer ring, each a list of exclusion rings using the same coordinates. An empty `poly_holes` means no exclusions. Each outer is filled and padded, then its own holes are removed; components are unioned, so an island in another component's hole stays covered.

`mask_pad` is a nonnegative pixel margin overriding the global pad. The default, -1, inherits the global pad. Motion uncertainty is added in either case. A zero value explicitly disables the base margin. Legacy reports lacking these fields retain their prior behavior. Empty, malformed, nonfinite, out-of-range or degenerate geometry falls back to the full padded box. Generated temporal samples of compound masks use boxes; observed samples retain their shape. Moving or resizing a shape in review converts it to a box. Review every detection before trusting a render.

Review uses the job's coverage, pad and face-shape settings, the same settings passed to rendering. Reopened jobs populate those options from report provenance. A later command-line render with different options uses those command-line values. The canvas contours are a topology and selection guide derived from the raster mask; individual boundary pixels can differ. The full-frame review tints the rasterized mask directly.
