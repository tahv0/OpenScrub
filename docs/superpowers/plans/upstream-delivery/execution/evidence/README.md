The [manifest](retained-manifest.json) records hashes and sizes of the retained files. Report prose and raw results are retained; relative documentation links are adjusted for this location. Raw logs may retain original whitespace and failed harness/setup invocations. Those failures are explained in the reports rather than removed from the evidence.

Scripts retain their original temporary paths and pinned-source assumptions. Reproduction may require recreating the isolated environment or adapting those paths; this archive is not a new application runtime or dependency bundle. Environments, model binaries, personal data, generated videos, large media and reproducible full-size report fixtures are excluded; fixture recipes and complete comparison hashes/results are retained. Absolute `/tmp` paths identify the original local execution, while the adjacent retained scripts/results provide the durable record.

Each upstream PR should carry only its relevant recipe, concise results and required regression tests. Before publication, replace scratch-only evidence references in that PR with its attached or committed material. No external publication is recorded here.

The [editor resize handoff](research/source-plans/editor-resize-source-plan.md.txt) preserves the contract used by completed Task164; the [exact editor backend handoff](research/source-plans/exact-editor-backend-source-plan.md.txt) remains unrun. Other selected source plans are retained alongside them as exact text snapshots. Contracts alone are not implementation evidence; the execution record identifies completed candidates.
