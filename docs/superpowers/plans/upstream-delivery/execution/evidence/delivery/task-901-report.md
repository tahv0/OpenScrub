## Remaining limits and handoff

Python hooks are safeguards for cooperative verification: ordinary audited writes and outward Python sockets are checked, but they are **not OS/native-process/network isolation**. Native extensions/processes, fd-relative operations/inherited descriptors, filesystem races, bypassed startup flags, deliberately changed environment/sys.path and alternate interpreters are outside this protection. Node inherits TMPDIR/prepared settings only. Controller lock ownership is per assigned scratch; root still schedules sole product runtime across different roots. A killed controller can leave a lock, which an owner must inspect rather than blindly remove. Server adapters own process cleanup and ports; there is no generic process-group manager. Caller-selected partial package/import inventories prove only those declared boundaries. Config hashes must come from an independently selected reviewed source, not observed imports.
