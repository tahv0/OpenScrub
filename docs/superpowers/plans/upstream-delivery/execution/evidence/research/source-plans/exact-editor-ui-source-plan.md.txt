## Proposed state/interfaces

- BE_VIEW gains serial/playbackSerial/trackLaunch/readySample/imageURL; object identity owns same-BE reopening. Page-local **BE_OPEN_INTENT** is captured by loadBoxEdit before any await, superseded by a newer open/close/panel/job intent. Check before accepting mediainfo, replacing slot or report continuation; old same-BE reentry cannot retire/remount newer content. Retained subtree stays mounted until current replacement.
- Page-local EDIT_SAMPLE_IO={active:null,wanted:null}; latest desired={view,serial,t}. Active remains occupied through fetch/body AND detached decode/apply/failure cleanup, bounding candidate images/URLs. Retirement never frees it early.
- **beInvalidateSample(view,message)** increments serial, clears readiness, ends drag/anchor/float/selection/handles/pointer capture through beEndGesture; preserves every pending delta/precondition/audio/choice.
- **beRequestSample(view,t)** invalidates/replaces wanted/pumps if idle. Await body, decode/apply and URL cleanup before releasing own active slot; discard stale bodies before decode. Retired decode completion cleans up then latest desired runs. All continuations check view+serial.
- **beValidateSample(body,t)** checks version/policy, finite times, integer index/dimensions/raw i, source_ref/digests, origin/offset/boxes/full bases/JPEG and requested_s==t. Carry integer/canonical; no slider rederivation/context hashing.
- **beApplySample(view,serial,validated)** owns candidate URL/decode. Require actual displayed image decode/complete/matching natural dimensions and view.sync's current finite positive image transform before installing boxes/offset/canonical BE.t/readySample={serial,sample,precondition,rows,imageURL}. Label requested/canonical times distinctly; stale visible pixels stay uneditable. Revoke failed/replaced/unmounted URLs; late callbacks are inert.
- **beReady(view=BE_VIEW)** checks current view/serial, !playing, connected image/canvas, current URL/decoded dimensions and sync's applied image transform. Hidden/zero/resize cancels gestures; valid resize restores only same sample/current transform, no request/rebase.
- **b.geometry[rawIndex]={precondition}**: beCaptureGeometry(view,row) retains existing pending owner or deep-copies full ready sample/context/base on first mutation. Gestures capture/check view/serial/row on every continuation. Selection/scrub/Save never changes baseline.
- **d.submitted**=null or {payload,manualRefs/manualSnapshot,addRefs/addSnapshot,geometryOwners/geometrySnapshot}; deep values plus original-owner refs. hasReviewEdits/trim preserve unresolved owner.
- **acknowledgeGeometry(editor,submission,result)** validates all strict rows/family; clears only equal submitted kinds; preserves new/different values/kinds and advances owned baseline only to returned complete row. Remove owner only when neither kind remains.
- **beTrackCurrent(launch)** checks captured id/gen/editor/view/trackLaunch. One launch/poll at a time; no backend token/cross-client attribution claim.
