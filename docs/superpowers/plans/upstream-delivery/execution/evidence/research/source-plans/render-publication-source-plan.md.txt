## Review focus

Each condition below has an owning test in checkpoints 1–4:

1. Previous absence, symlinked parent/final entries and independently replaceable hardlink names must not become a blanket alias prohibition.
2. A legacy report callback may write then raise or return without writing; rollback/compatibility must match that actual behavior.
3. Descriptor unlink can fail after pair/status work; rollback must retain backups, and any surviving marker must force conservative recovery.
4. A failed mutation or rollback restoring identical bytes must invalidate a pending decoder; constructor errors during overlap must be discarded too.
5. Lazy stream opening, Range/conditional responses and early close must keep descriptor metadata and FILES ownership tied to the same generation.
