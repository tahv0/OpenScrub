# P08A Thumbnail Invalidation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans or the supervisor-selected superpowers:subagent-driven-development method to implement this plan task-by-task. Steps use checkbox syntax. Task8010 is preparation only; root reviews/adopts this handoff before Task801 implementation.

**Goal:** Make review crops and lightbox images correspond to the current coherent report/source generation, including browser revisits and late producers, while preserving ordinary editing and exact geometry draft ownership.

**Architecture:** Extend the accepted per-job source/report/lifetime owner at `6fde5ad60c6d78d69dbbd8e049a9196f15e4095f`. Add one small thumbnail state to `_JobFiles`, one private shared producer/cache helper, versioned HTTP adapters and bounded image-only browser recovery. Keep source coherence separate from exact timing/backend admission and keep every mutation on its latest private raw report.

**Tech Stack:** Python >=3.9, existing Flask/OpenCV/NumPy, embedded APP_JS/PAGE, stdlib staging and hashing; prepared Chromium/Playwright only for delivery validation.

**Spec:** `thumbnail-identity-contract-research.md` **including its final no-full-input-hash amendment**; `exact-editor-contract-research.md` final adopted source/report/geometry amendments; Task1001/1002 final acceptance and supervisor rulings; P08/P08A/P08B in `docs/superpowers/plans/upstream-delivery/02-large-video-performance.md`; `task-8010-brief.md`; `p08a-accepted-owner-handoff.md`. Local SDD filenames are relative to this plan directory. The immutable accepted source takes precedence over old 12919c9 line numbers/provisional owner work in the research.

## Global Constraints

- Python >=3.9; no new dependency, model, training, user setting, report schema, production root file, durable source registry or token history.
- No whole-video/full-report hash for generation naming, no whole-input scan, no per-scrub probe, no retained report tree. Small raw-row fingerprints and encoded-JPEG hashes have separate purposes.
- Keep `_load_job_report(job)` fresh and mutable for saves/tracking/render; preserve unknown fields, disabled/zone rows, full ordering, manual identity, P07a acknowledgement and P07b replay-first.
- Reuse `FILES`, `_JobFiles.report_lock`, incarnation/source epoch/current descriptor, committed report epoch, pending adoption and operation Event identity. No parallel source owner.
- Admission/related-source reservation happens under VAULT_LOCK outside report_lock; parsing, probing, decoding, encoding, bulk reads, cleanup, waits and lease release happen outside both locks. Short regular-file open/stat/fstat/final rename and constant-size metadata publication belong to the coherent boundary.
- A coherent ordinary source remains usable when `policy_error` is set or exact CFR/backend/timing policy rejects it. P08A never calls `_exact_policy`, `exact.timeline` or `_read_exact_source` to admit thumbnails.
- Thumbnail V is not a geometry precondition. Choice/audio publication may retire V while exact source/timeline/row baseline remains valid. Image recovery never remounts an editor, rebases geometry or clears drafts.
- Pending/retired/failed scan adoption and observed source replacement cannot be bypassed by a legacy fallback. Reliable observed stamps plus managed in-process epochs define the supported guarantee; equal-observed-attribute external mutation, weak filesystem identity and arbitrary cross-process writers remain outside it.
- All future commands require root's task-local source/runtime allowance. Preparation ran no product/test/browser/build/media workload and changed no source/ref/index/HEAD.

## Review Focus

1. Unsupported exact metadata/raw VFR policy with a coherent ordinary source: thumbnails remain usable; strict samples retain their current refusal. Owned by Task1 tests.
2. Initial legacy dict versus removed/malformed provenance, pending/retired pair and observed replacement: only the initial tolerant association is permitted. Owned by Task1 tests.
3. Successful unrelated choice/audio saves change thumbnail V without invalidating geometry drafts or uncertain-save ownership. Owned by Tasks2/4 tests.
4. An old matching ETag, a partially read cache file, a late pregen fill or a cancelled operation cannot make obsolete pixels current. Owned by Tasks2/3 tests.
5. Failed unlink/encoding/thread start and vault/unlock with already registered jobs cannot retain an unbounded plaintext history or revive old V. Owned by Tasks2/3 tests.

## Task3: one pixel recipe, atomic producers and coherent HTTP

**Files:** thumbnails.py, openscrub_web.py; tests/test_thumbnail_io.py and existing report/source lifecycle controls.

**Interfaces produced:**

- `recipe_for_row(row,render_state,kind) -> Recipe`: immutable fields kind, cbox (four floats), candidate_times (at most three floats), indices (matching ints), offsets (matching two-float tuples), padding, jpeg_quality, outline_expansion, outline_thickness and recipe_version; no retained timeline copy. Preserve demand's last valid crop when no nonblank candidate succeeds. Pregen may accept only a successful nonblank first candidate; otherwise leave demand to try fallbacks. Detframe uses first candidate, outline box expanded4/thickness3, JPEG84 and its own kind. Recipe discriminator changes whenever any timing/decoder/clipping/color/scale/rotation/outline/JPEG rule changes. This intentionally makes formerly mismatched end-boundary decode/cum behavior coherent.
