# Reject malformed source and derived render geometry

A zero/reversed source box can be hidden by coverage expansion, while nonfinite or overflowed coordinates can reach clipping/native painting after render resources have opened. Validate enabled source geometry before coverage and at both direct SDR/HDR entry points, then check actual coverage/frame/band calculations before clipping or conversion. Errors identify the stage, detection ordinal and field without including detected text or input values.

Keep ordinary Python/NumPy arithmetic and rounding, finite signed padding, point/negative detection times, trajectory reuse, legal empty/offscreen intersections, and tolerated finite negative frame-count metadata. Metadata guards reject unusable dimensions/conversions without adding a count-sign policy. Separate the public source-validating render wrappers from their existing computation bodies so concealed coverage may still round a valid tiny box to an empty integer box; ordinary positive padding still paints its original coverage. Public signatures/defaults and polygon fallback behavior remain unchanged. Add focused tests and include them in the sdist.
